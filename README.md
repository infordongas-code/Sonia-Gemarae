# Homenagem à Dra. Sonia Guimarães — Consciência Negra

Projeto web desenvolvido em **HTML5, CSS3 e JavaScript puro** em homenagem à **Dra. Sonia Guimarães**, primeira mulher negra brasileira doutora em Física e professora do Instituto Tecnológico de Aeronáutica (ITA).

## Estrutura de Pastas
```
sonia_guimaraes_consciencia_negra/
├── .vscode/
│   ├── extensions.json   # Extensões recomendadas (Live Server)
│   └── settings.json     # Configurações do editor
├── css/
│   └── style.css         # Estilos responsivos e identidade visual
├── js/
│   └── script.js         # Linha do tempo interativa, menu mobile e quiz
├── index.html            # Estrutura semântica da página
└── README.md             # Instruções de uso
```

## Como abrir no Visual Studio Code (VS Code)
1. Extraia o arquivo `.zip` em uma pasta no seu computador.
2. Abra o **VS Code**, clique em **Arquivo > Abrir Pasta...** (`File > Open Folder...`) e selecione a pasta `sonia_guimaraes_consciencia_negra`.
3. Instale a extensão **Live Server** (caso ainda não tenha).
4. Clique com o botão direito sobre o arquivo `index.html` e selecione **"Open with Live Server"** (ou dê duplo clique no `index.html` pelo explorador de arquivos para abrir no navegador).
